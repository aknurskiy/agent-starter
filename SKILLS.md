# Каталог навыков (skills) для Claude Code

Навыки — это готовые «суперспособности» для вашего агента: методологии, генераторы кода, дизайн-гайды. Ставятся одной командой.

> **Принцип.** Мы НЕ копируем чужие навыки к себе в репозиторий. Мы даём ссылки на **официальные репозитории авторов**. Ставьте из источника — так вы получаете свежую версию и уважаете труд авторов. Всё ниже — открытые пакеты сторонних разработчиков, а не наша разработка.

---

## 1. Superpowers — методология разработки (обязательный)

Полноценная методология для Claude Code: планирование → спецификация → разработка через субагентов → TDD (тесты вперёд). Дисциплина, на которой держится качество агента.

- **Автор:** Jesse Vincent (obra)
- **Источник:** https://github.com/obra/superpowers
- **Установка:**
  ```
  /plugin install superpowers@claude-plugins-official
  ```

---

## 2. AgentOS Skills — senior-brainstorm + telegram-bot-builder

Два навыка из интенсива AgentOS (Edge Lab):
- **senior-brainstorm** — senior-архитектор для EdTech/SaaS: выбор стека, паттерны, threat modeling _(лицензия MIT)_.
- **telegram-bot-builder** — генератор Telegram-ботов на Python (aiogram 3 / PTB v21) или TypeScript (grammY).

- **Автор:** qwwiwi (Edge Lab)
- **Источник:** https://github.com/qwwiwi/agentos-skills
- **Установка (пример):**
  ```
  claude skill add https://github.com/qwwiwi/agentos-skills/raw/main/telegram-bot-builder.skill
  ```

---

## 3. ponytail — минималистичный чистый код

Заставляет агента писать минимум кода, который решает задачу: сначала искать готовое (в проекте, в стандартной библиотеке, в платформе), а не плодить лишнее. При этом НЕ жертвует валидацией, обработкой ошибок и безопасностью. Код становится чище и короче.

- **Автор:** Dietrich Gebert
- **Источник:** https://github.com/DietrichGebert/ponytail
- **Установка:**
  ```
  /plugin marketplace add DietrichGebert/ponytail
  /plugin install ponytail@ponytail
  ```

---

## 4. impeccable — дизайн сайтов и лендингов

Дизайн-гайданс для агента + детектор «AI-слопа» во фронтенде (одинаковые шрифты, фиолетовые градиенты, карточки в карточках). Помогает получать сильный визуальный результат, а не «сгенерировано нейросетью».

- **Автор:** Paul Bakaus
- **Источник:** https://github.com/pbakaus/impeccable
- **Установка:**
  ```
  npx impeccable install
  ```
